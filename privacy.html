Privacy Policy

Pace Publisher. Effective October 22, 2026.

Pace Publisher is a personal tool that uploads videos made for the Pace account to that account's TikTok drafts. This policy explains what it accesses and what it does with it.

Whose data

Pace Publisher only connects to one TikTok account: the Pace creator's own account. It is not offered to other users and does not access anyone else's TikTok account.

What it stores

  • The TikTok access token issued when the account owner authorizes the app.
  • The TikTok account ID for that account.

Both are stored locally on the account owner's own computer. They are not stored on any server run for this app.

How it is used

The token and account ID are used only to upload the account owner's own videos to that account's TikTok drafts. They are not used for anything else.

What it does not do

  • It does not collect personal data from anyone else, including viewers, followers, or commenters.
  • It does not sell, rent, or share data with anyone.
  • It does not use data for advertising or profiling.

Removing access

Access can be revoked at any time from the connected apps settings in TikTok. Deleting the locally stored token and account ID removes them from the computer.

This website

This site uses no cookies, analytics, or trackers. It is hosted on GitHub Pages, and GitHub may log basic request data such as IP addresses under its own privacy statement.

Changes
